# Cybera feature-parity matrix

Reference: untouched Cybera 1.9.rc2 VB6 source under third_party/original-source. The modern bridge never joins or impersonates the XP workstation TCP protocol.

| Legacy capability | Web/API status | Safe implementation path |
| --- | --- | --- |
| Server health | Implemented | Health and status endpoints |
| Workstations and sessions | Adapter-needed | Read-only snapshot and allowlisted relay actions |
| Clients/accounts | Adapter-needed | Snapshot plus host-local relay |
| Cards, recharge, credit | Adapter-needed | Snapshot plus card.recharge relay action |
| Pricing/self-service | Adapter-needed | Snapshot plus reviewed relay |
| Operators/roles | Adapter-needed | Snapshot only until a role adapter exists |
| Journals, reports, stats | Adapter-needed | Snapshot/export adapter |
| Configuration and backups | Safely deferred | No direct Jet/Access writes |
| Lock, unlock, pause, resume, end | Adapter-needed | Allowlisted relay and audit |
| Shutdown/message | Adapter-needed | Allowlisted relay and audit |
| Screen following/replication | Safely deferred | Isolated capture adapter and privacy review |
| XP lockdown/remote registry | Safely deferred | Legacy-only; never browser exposed |

## Snapshot contract

Set Bridge:LegacyStatusFile to a trusted, atomically replaced JSON file generated by a host-local adapter. It may expose workstations, sessions, accounts, cards, pricing, operators, journal, reports, and configuration. Missing collections return an explicit unavailable response; no live values are inferred.

## Command adapter contract

Enable Bridge:CommandRelay only after deploying a loopback-only adapter. Mutations require an API key, an allowlisted action, a target ID, a 16+ character idempotency key, relay availability, and Bridge:AuditLogPath. The bridge writes JSON Lines audit records after every relay attempt. The adapter must independently authorize, validate, and audit before touching Cybera.
